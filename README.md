# Simple Trivia APP

A simple web-based trivia quiz game built with HTML, CSS, and JavaScript. The game uses the [Open Trivia Database API](https://opentdb.com/) to get random questions on various topics.

## Features

- Three difficulty levels: Easy, Medium, and Hard
- Random questions with four possible answers
- Score tracking and a personal best score that is saved between games
- Instant feedback showing correct and incorrect answers
- Option to change the background color

## Technologies Used

- **HTML & CSS** – Website structure and design
- **JavaScript** – Game logic and user interactions
- **Open Trivia Database API** – Provides random trivia questions
- **Local Storage** – Saves the player's best score

## How to Play

1. Open `index.html` in your browser.
2. Choose a difficulty level.
3. Answer questions and try to beat your best score!

An internet connection is required to load new questions.

## About the Project

This project was created to practice web development, working with external APIs, and building interactive applications using JavaScript.
